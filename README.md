# iShopping

Protótipo de aplicação de gestão de compras domésticas, desenvolvido no âmbito da unidade curricular de Laboratório de Desenvolvimento II (CTeSP em Desenvolvimento para Dispositivos Móveis, ISTEC, 2026/2027).

## Funcionalidades

- Login de utilizadores
- Gestão de utilizadores, tipos de artigo, artigos e orçamentos
- Planeamento de compras e modo Compra
- Exportação de compras fechadas para CSV
- Estatísticas e sugestões de orçamento e de lista de compras
