# iShopping

Protótipo de aplicação de gestão de compras domésticas, desenvolvido no âmbito da unidade curricular de Laboratório de Desenvolvimento II (CTeSP em Desenvolvimento para Dispositivos Móveis, ISTEC, 2026/2027).

- Gonçalo Dias (2025185)

Turma L, Grupo 1

## Funcionalidades

- Login de utilizadores
- Gestão de utilizadores, tipos de artigo, artigos e orçamentos
- Planeamento de compras e modo Compra
- Exportação de compras fechadas para CSV
- Estatísticas e sugestões de orçamento e de lista de compras

## Tecnologias

- Backend: Java e Spring Boot
- Base de dados: PostgreSQL 16, com Docker Compose
- Frontend: React Native com Expo

## Instalação e execução

A preencher quando a stack estiver definida.

## Organização do repositório

- `main`: versão estável, apenas entregas de fim de sprint
- `develop`: integração do trabalho em curso
- `feature/ILG-<n>-<descricao>`: uma branch por tarefa do Jira
- `docs/`: documentação do projeto

Scrum com 4 sprints, acompanhado no Jira (espaço iShopping LDII G1).
